### Automatic validation and deployment

The `Deploy resource website` workflow checks the site's HTML, local assets, links, and JavaScript syntax. Pull requests are validated without publishing. Updates to `site/` on `main` are automatically published through GitHub Pages; the workflow can also be run manually.

To update the directory, edit the cards in `site/index.html` and keep `MCP-LINKS.md` current. The existing Markdown exercise files and workflows are preserved.

MCP URLs are unverified bookmarks, not authenticated integrations. Do not add passwords, API keys, OAuth tokens, or private account links to this public repository.
